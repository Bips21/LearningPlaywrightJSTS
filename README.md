# Learning Playwright JS/TS

A hands-on repository for learning JavaScript and building toward browser automation with Playwright and TypeScript. The current chapters cover JavaScript fundamentals alongside prompt-engineering and QA material.

## Chapter Structure

- `00_Chapter_Prompt_Eng/Selenium_Framework/`: prompt engineering, problem statements, anti-hallucination guidance, and a generic QA template.
- `01_Chapter_JS_Basics/`: Hello World and basic math examples.
- `02_Chapter_JS_Keywords_Identifiers/`: JavaScript declarations, keywords, identifier rules, naming conventions, and comments.
- `03_Chapter_JS_Literals/`: number, boolean, null, undefined, BigInt, and special numeric values.
- `04_Chapter_JS_Operators/`: assignment, arithmetic, comparison, and logical operators.

## Learning Objectives

- Build confidence with JavaScript syntax and the Node.js runtime.
- Understand identifiers, declarations, values, and JavaScript's primitive types.
- Practice arithmetic, assignment, comparison, and logical operators.
- Develop a foundation for writing and testing browser automation with Playwright.

## Run an Example

Install Node.js, then open a terminal at the repository root and run an individual JavaScript file:

```sh
node 01_Chapter_JS_Basics/01_HelloWorld.js
node 04_Chapter_JS_Operators/21_Arithmetic_Op.js
```

Each example is a standalone script. Run one file at a time; no package installation is needed for the current examples.
